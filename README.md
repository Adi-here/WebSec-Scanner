# Automated Web Security Scanner

A beginner-friendly Python project that audits websites for common security misconfigurations and produces a scored report with charts.

## Project Description
The scanner sends HTTP requests to a list of target URLs and checks:
- **Security headers:** HSTS, Content-Security-Policy, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy
- **CORS policy:** reflected origins, wildcard `*`, and credentials allowed for untrusted origins
- **Cookie flags:** `Secure`, `HttpOnly`, `SameSite`
- **Information leaks:** `Server` and `X-Powered-By` headers

Each site gets a score out of 100 and a grade (A to F). Results are saved as CSV/JSON and visualised with matplotlib.

To keep it safe and fully offline, the notebook starts three local demo servers (weak, mixed, hardened) and scans those by default.

## Dataset
No external dataset is used. The data is generated by the scan itself:
- `scan_findings.csv` – every issue found (URL, check, severity, issue, fix)
- `scan_summary.csv` – score and grade per site

Optionally, add your own URLs (websites you own or have permission to test) to the `TARGETS` list.
Dataset link: N/A (self-generated; outputs are saved in the project folder after running).

## Technologies Used
Python 3.9+, requests, pandas, matplotlib, Jupyter Notebook, `http.server` (demo servers)

## Setup and Run
```bash
# 1. (optional) create a virtual environment
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 2. install dependencies
pip install -r requirements.txt

# 3. open and run the notebook
jupyter notebook Adi_WebSecurityScanner.ipynb
```
Then choose **Kernel > Restart & Run All**. No internet connection is needed for the default demo targets.
